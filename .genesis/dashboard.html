Your development workspace

Build a small-scale financial-document intelligence demo, inspired by Moody's multi-agent RAG architecture, as a personal proof-of-work project to show a credit-ratings/DCM finance professional at Adani Group. Scope: (1) ingest a handful of PUBLIC financial documents only - public annual reports, bond prospectuses, disclosures - never confidential or internal company data; (2) classify each page as text-heavy, table-heavy, or chart/image, and route to a matching extraction method; (3) chunk, embed, and store extracted content in a local vector store (Chroma or FAISS, no cloud infra); (4) implement an agentic retrieval loop - plan, search, reflect, iterate, synthesize with citations - instead of single-shot vector search; (5) implement 2-3 narrow specialist agents (credit analysis, ESG/climate, compliance) plus a router agent that decides which specialist(s) to invoke per query; (6) output a structured analysis note with citations, in the style of a first-pass credit-rating rationale note. Runs locally, small scale, built primarily via Claude Code, using the Anthropic API.
